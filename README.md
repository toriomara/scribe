# Scribe

Telegram userbot: записываете голосовое в «Избранное», Scribe распознаёт речь
и отправляет текст **от вашего имени** выбранному собеседнику или в группу.

> Статус: логика покрыта тестами; с живым аккаунтом ещё не проверялось.

## Как пользоваться

Всё происходит в «Избранном» (Saved Messages):

| Что написать | Что произойдёт |
|---|---|
| `.to @username` / `.to +79991234567` / `.to Название чата` | Выбрать получателя |
| 🎤 голосовое (или аудиофайл) | Распознать в черновик |
| `+` | Отправить черновик от вашего имени |
| `-` | Отменить черновик |
| любой текст при открытом черновике | Заменить текст черновика |
| `.status` / `.help` | Текущее состояние / справка |

Ответы Scribe начинаются с 🤖. Обычные заметки в «Избранном» без открытого
черновика бот не трогает. Черновик и получатель хранятся в памяти и сбрасываются
при перезапуске.

## Требования

- Node.js ≥ 22
- `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org) → API development tools

## Настройка

1. `npm install`
2. Создайте файл `.env` в корне проекта:

   ```dotenv
   TELEGRAM_API_ID=1234567
   TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
   TELEGRAM_SESSION=
   OPENAI_API_KEY=

   # Необязательные (значения по умолчанию):
   # OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe
   # TRANSCRIBE_LANGUAGE=ru
   # MAX_VOICE_SECONDS=300
   ```

3. `npm run login` — введите телефон, код и пароль 2FA. Скопируйте выведенную
   строку `TELEGRAM_SESSION=...` в `.env`.
4. `npm start` — должно появиться «Scribe запущен как …».

> ⚠️ `TELEGRAM_SESSION` даёт полный доступ к аккаунту. Не коммитьте `.env`
> (он в `.gitignore`). При утечке: Telegram → Настройки → Устройства → завершить сеанс.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run login` | Интерактивный вход, выдаёт строку сессии |
| `npm start` | Запуск userbot |
| `npm test` | Тесты (vitest) |
| `npm run lint` | ESLint |
| `npm run typecheck` | Проверка типов |

## Из чего состоит

src/commands.ts — разбор команд.
src/state.ts — логика черновика.
src/dialogs.ts — поиск чата по названию.
src/transcriber.ts — распознавание речи. По умолчанию модель gpt-4o-mini-transcribe и русский язык.
src/bot.ts — связка всего этого с Telegram.
README.md — обновлённая инструкция.
